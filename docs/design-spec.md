# 际联 SaaS 页面与视觉设计规范

可编辑版本：[Figma 页面 Mock](https://www.figma.com/design/4i3aFEZX5kfSf4Ty19kbFE)

## 1. 设计方向

以仓库内 Si Educational 模板作为官网视觉与组件结构基线，但不沿用其课程平台品牌和紫色主题：

- 复用响应式 Header、Footer、Hero、课程卡片、导师卡片、评价和内容分区结构；
- 将课程目录改造为留学、签证、求职和语言指导服务目录；
- 大字号深蓝标题配科技蓝主按钮；
- Hero 使用克制的浅蓝径向光晕，不使用原模板的紫色与暖米色主题；
- 卡片用图片、能力标签、标题和摘要建立内容层级；
- 只在 Hero 评分卡和搜索/预约卡使用轻量半透明效果；
- 保留高可读性，不使用大面积深色背景或过多玻璃效果。

## 2. 视觉系统

### 2.1 色彩

| Token | 色值 | 用途 |
|---|---|---|
| Primary Blue | `#4D6BFE` | 主按钮、激活态、链接 |
| Primary Dark | `#314BD6` | Hover、按下状态 |
| Brand Deep | `#14245F` | 标题、品牌深色、关键数据 |
| Sky Accent | `#38BDF8` | 轻量高亮、进度节点 |
| Ink | `#101828` | 正文主色 |
| Muted | `#667085` | 辅助文字 |
| Canvas | `#FFFFFF` | 主背景 |
| Surface | `#EEF3FF` | 分区背景、卡片底 |
| Border | `#DCE5FF` | 分割线和输入框 |
| Success | `#129C8B` | 完成、成功 |
| Warning | `#B54708` | 待处理/提醒 |

### 2.2 字体

- 中文：PingFang SC / Microsoft YaHei / Noto Sans CJK SC；
- 英文与数字：Inter / 系统无衬线字体；
- Demo 阶段不从 Google Fonts 在线加载字体，避免国内网络环境导致页面阻塞；
- H1：64/72，700；移动端 40/48；
- H2：40/48，700；移动端 30/38；
- 正文：16/28；
- 标签：13/20，600。

### 2.3 布局

- 桌面画板 1440px，内容最大宽 1200px；
- 12 栏栅格，24px gutter；
- Section 上下间距 96px；移动端 64px；
- 卡片圆角 16px，按钮使用胶囊圆角；
- 关键页面必须同时设计 1440px 和 390px。

### 2.4 标志性元素

“路线卡 Route Card”：把国家、申请季、任务进度表示为一条可延伸的路径节点。它既是品牌视觉，也是真实服务状态组件；避免无意义装饰。

## 3. Mock 范围

Figma 第一版包含以下桌面核心屏：

1. 官网首页；
2. 留学服务/内容列表；
3. 导师/顾问列表与人员详情；
4. 学生案例列表与详情；
5. 三步预约页；
6. 学生 Portal 总览；
7. Case 服务计划；
8. 导师预约与学生工作台；
9. 管理员 Lead/Case 列表。

## 4. 页面结构

### 4.1 官网首页

```text

│ 大标题与价值主张              人物/路线视觉          │
│ [免费评估] [了解服务]         服务标签与可信数据      │
├ 精选服务：留学申请 / 学签 / 旅游签 ────────────────┤
├ 精选案例（1 大卡 + 3 小卡，参考 Featured Posts） ───┤
├ 服务流程 Route Card ──────────────────────────────┤
├ 导师推荐 ─────────────────────────────────────────┤
├ 最新指南（内容卡片，参考 Recent Posts） ───────────┤
└ 联系方式 / 合规声明 / Footer ──────────────────────┘
```

### 4.2 预约页

```text
┌ 返回官网        1 背景信息 — 2 选择导师 — 3 选择时间 ┐

│                                            [继续]     │

```

### 4.3 学生 Portal

```text
┌ Sidebar ───────────┬ 当前 Case / 申请季切换 ─────────┐
│ 总览               │ 下一步行动（主卡）              │

│ 服务计划           │ 近期截止日期 / 待审阅文件        │
│ 交付物             │ 负责人和下一次预约              │
│ 申请追踪           │                                  │

```

## 5. 交互与响应式

- 导航在 < 768px 收入抽屉，主 CTA 保留；
- 首页 Hero 在平板以下改为单列，图片在文案后；
- 卡片网格：桌面 3/4 列、平板 2 列、手机 1 列；
- Portal 在 < 1024px 将 Sidebar 变为 Sheet；
- 表格在手机端转为卡片，不做横向压缩；
- 所有点击目标至少 44×44px；
- 动画只用于 Hero 入场和 Route Card 状态推进，尊重 reduced motion。

## 6. 内容语气

- 具体、克制、可信，不使用“保录”“百分百过签”；
- CTA 使用动作：“获取免费评估”“查看可预约时间”；
- 错误给出解决方法：“该时段刚被预约，请选择其他时间”；
- 空状态指向下一步：“还没有申请项目，先确认选校清单”。

## 7. Figma 与 PRD 一致性更新清单

> 依据最新业务决策整理。现有 Figma 首版仍是旧视觉方向；下一轮需按 Si Educational 结构与本规范科技蓝 Token 更新。

### 7.1 现有画板修改

#### 01 官网首页

- 保留“获取免费评估”主 CTA；
- 将首次评估明确标注为“20 分钟免费线上背景评估”；
- 在桌面页头、移动菜单、页尾和联系页增加微信客服入口，展示二维码、微信号复制及无法唤起微信时的说明；
- 服务分类增加“求职指导”和“语言指导”卡片及独立详情页入口；
- 服务流程补充“账号激活”和“合同 + 服务确认单”两个节点；
- 会议平台文案统一为“腾讯会议或负责咨询的服务人员提供的其他会议链接”；
- 不出现 Google Calendar 或 Zoom 作为用户可见的必要条件。

#### 02 导师团队

- 公开人员卡片只展示基础身份“导师”或“顾问”；“主导师/专项导师”是 Case 内的分工标签，不是固定的公开身份：
  - 导师：负责留学定位、文书和申请服务流程；
  - 顾问：负责签证和其他事务型服务；
- 卡片增加角色标签与可服务的 CaseType；
- 卡片展示求职指导、语言指导等能力标签；具备能力的导师或顾问均可提供对应服务；
- 筛选项增加“导师 / 顾问”，不再把所有人员统称为导师；
- 管理员是后台权限，不作为官网团队卡片的职业标签。
- 学生服务团队需明确展示唯一主导师、多个专项导师及顾问，并标注各自负责的任务；
- 管理端需支持为留学 Case 指定唯一主导师、多个专项导师和任务协作者，为签证 Case 指定负责顾问。

#### 03 预约咨询

- 主标题改为“20 分钟免费首次背景评估”；
- 辅助说明增加“系统会为本次咨询预留最多 45 分钟”；
- 邮箱字段明确标注：
  - 必填；
  - 用于预约确认和账号激活；
- 成功页增加两个独立状态：
  - 预约已确认；
  - 激活邮件已发送，激活后可登录；
- 增加“会议开始前 12 小时可通过邮件链接取消或改期”；
- 明确提示系统会在会议开始前 24 小时发送提醒；
- 学生不需要选择腾讯会议或手动链接，该选择由负责咨询的服务人员/系统处理；
- 会议链接未生成时显示“会议链接稍后发送”，不得阻塞预约成功。

#### 04 学生 Portal

- “我的方案”改为“签约与服务”，包含：
  - 通用合同条款 PDF；
  - 本次服务确认单；
  - 签字合同上传；
  - 付款凭证上传；
  - 管理员核验状态；
- 未完成签约与付款核验前，付费服务模块显示锁定原因；
- 服务激活后，只显示服务确认单购买的 Service Items；
- 求职指导模块展示目标岗位、简历版本、模拟面试、行动任务与反馈；
- 语言指导模块展示目标、当前水平、学习计划、练习任务与阶段测评；
- 申请追踪页展示平台状态、外部来源、最后同步时间和“待核对”状态，学生端仅显示已确认进度；
- 保留“下一步行动 + 服务路线”的首页结构；
- 账号内不创建家长角色；合同详情单独显示实际签署人和付款人。

### 7.2 需要新增的画板

#### 05 签约与服务确认

```text
┌ 签约进度：表达兴趣 — 合同预览 — 答疑 — 上传签字合同 — 付款核验 ┐
│ 左：通用合同条款 PDF 预览                                     │
│ 右：本次服务确认单                                            │
│     服务项目 / 范围 / 原价 / 折扣 / 最终价格 / 有效期          │
│ [预约 60 分钟答疑] [下载合同] [上传签字合同]                   │
└───────────────────────────────────────────────────────────────┘
```

#### 06 预约成功与账号激活

- 预约状态、导师、时间和会议链接状态；
- “激活邮件已发送至 xxx@xxx.com”；
- 重新发送激活邮件；
- 取消/改期签名链接；
- 腾讯会议链接或“等待导师补充链接”状态。

#### 07 导师/顾问预约详情

- 学生背景摘要；
- AI 初评报告默认仅负责首次咨询的主导师或签证顾问可见；专项导师仅在被分配且确有任务需要时可见；
- 报告编辑与“分享给学生”开关；
- 腾讯会议自动创建 / 手动会议链接切换；
- 咨询摘要、适配度、下一步和跟进日期。

#### 08 管理员服务与价格配置

- 套餐和单项服务；
- 服务范围与 Service Code；
- 基础价格、折扣和启停状态；
- 修改价格不影响历史服务确认单的提示；
- 通用合同模板版本管理。

### 7.3 原型交互

- “表达签约兴趣”解锁签约页面；
- “预约 60 分钟答疑”只在完成初评后可用；
- 上传签字合同和付款凭证后进入“等待管理员核验”；
- 管理员核验后，锁定模块转为对应服务入口；
- 取消预约同时更新平台预约状态，不把腾讯会议取消视为唯一成功条件。
